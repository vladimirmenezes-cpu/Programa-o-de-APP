# Programa-o-de-APP
Atividades e trabalhos da matéria de Programação de aplicativos do segundo modulo 

Início da aula.
Fazer login no GitHub no navegador de internet

Fazer login no GitHub via terminal:

gh auth login
Aperte a tecla enter até gerar um código
Copie o código gerado no terminal e cole no navegador de internet
Clonar o repositório usado nas aulas para o computador:
gh repo clone nome-do-repositorio
Entrar na pasta criada com o clone do repositório:
cd nome-do-repositorio
Abrir o VSCode pelo terminal:
code .
